# Contribuindo

Relatos de outras unidades Prelude são especialmente úteis. Ao abrir uma
issue, informe:

- versão e arquitetura do macOS;
- saída de `ls /dev/cu.usbserial-*`;
- se `prelude-bridge --monitor --no-midi` mostra bytes ao tocar;
- módulo/instrumento conectado e aplicativo MIDI utilizado.

Não anexe drivers proprietários, instaladores Windows ou capturas que contenham
informações pessoais. Para contribuir com código, execute `swift test` antes de
abrir o pull request e mantenha mudanças pequenas e focadas.
